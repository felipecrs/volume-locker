# Release Notes

## What's New

### Independent Communication Priorities
- You can now set separate priority lists for communication devices.
- Voice calls and regular media playback can route to different devices automatically.
- For example, keep music on speakers while calls automatically use your headset.
- Input devices also support independent communication priorities for microphones.

### Flexible Communication Fallbacks
- Communication priorities can now include your regular device priority as an entry.
- Prefer a headset for calls when connected, and fall back to your normal speakers otherwise.
- Move or remove the fallback entry at any time.

### Streamlined Priority Menus
- Priority lists are now organized in dedicated settings submenus.
- The main tray menu is shorter and easier to navigate.
- When adding a device, you can choose **Add to top** or **Add to bottom**.
- **Notify on restore** is now located inside each priority settings submenu.

### Current Device Status at a Glance
- Active default and communication devices are displayed directly under **Current: <device>**.
- Star indicators were removed from the device list in favor of these clear labels.

### Temporary Overrides for Communication
- Temporary device overrides now support communication devices.
- Temporarily switch calls to another device without changing your saved priorities.
- Temporary menu labels display the currently active override.

### Independent Notifications
- Toggle restore notifications separately for regular audio and communication audio.
